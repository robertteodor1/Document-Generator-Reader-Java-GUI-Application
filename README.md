# Document Generator and Reader – Java GUI Application

This Java application provides a graphical interface for generating and reading Word and Excel documents. It is built using Swing for the GUI and Apache POI for file processing.

## 🎯 Project Goals

- Enable users to generate `.docx` documents dynamically.
- Read content from Word (`.docx`) and Excel (`.xlsx`) files.
- Offer an intuitive desktop interface for interacting with structured data.
- Demonstrate integration of Apache POI with a clean, modular Java architecture.

## 🛠 Technologies Used

- **Java** (JDK 17+)
- **Swing** (for GUI)
- **Apache POI** (for Word and Excel file operations)

## 📂 Key Components

- `GeneratorGUI.java` – main GUI class  
- `GenerateWordDocument.java` – logic for generating `.docx` files  
- `ReadWordDocument.java` – logic for reading `.docx` documents  
- `ReadExcelFile.java` – logic for parsing `.xlsx` files  
- `DocumentContentHolder.java` – data structure for content management

## ✅ Features

- Simple and responsive Java Swing interface
- Dynamic generation of Word documents based on input fields
- Reading and displaying structured Word and Excel content
- Modular codebase for future extensions (e.g., PDF, templates, formatting)

## 🚀 How to Run

1. Clone the repository
2. Import the project in your IDE (e.g., IntelliJ or Eclipse)
3. Make sure Apache POI is included in the build path
4. Run `GeneratorGUI.java`
